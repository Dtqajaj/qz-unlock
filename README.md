# 吃鸡枪王战场 · 全解锁

4399 H5 小游戏《吃鸡枪王战场》(gameId=100068063) 的服务端存档写入工具。

**写的是服务端存档，不是本地内存。关页面、换设备、明天再登都还在。**

## 在线使用

**<https://dtqajaj.github.io/qz-unlock/>**

1. 点「打开游戏页面」，登录 4399
2. 从地址栏复制整条 `index_hao.html?userId=...&sign=...` 链接
3. 粘贴 → 解析凭证 → 开始刷取
4. 等进度条走完（约 1 分钟）

## 三种用法

### 用法 A：网页（推荐）

```bash
cd qz-unlock
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/web/`

1. 点「打开游戏页面」，登录 4399
2. 从地址栏复制整条 `index_hao.html?userId=...&sign=...` 链接
3. 粘贴 → 解析凭证 → 开始刷取
4. 等进度条走完（约 1 分钟）

### 用法 B：浏览器控制台

1. 正常进游戏，按 F12 打开控制台
2. 复制 `dist/console.js` 全部内容，粘贴回车
3. 自动开始刷，控制台看日志

### 用法 C：油猴脚本

装 `dist/qz-unlock.user.js`，进游戏自动刷，面板可开关。

## 为什么不能用账号密码

`sign` 是 4399 服务端对 `(userId, userName, time)` 做的签名，**客户端伪造不了**。
4399 登录接口还有图形验证码，光有账号密码拿不到 `sign`。

所以实际的凭证流程是：

```
用户登录 4399
   ↓
4399 框架签发 sign（h.api.4399.com/intermodal/user/grant2）
   ↓
iframe URL 带上 userId / userName / time / sign
   ↓
游戏客户端把这四个值塞进 10000 wc1 登录包
```

工具拿到的就是这个 URL 里的四个值。**签名有效期有限，过期要重新进游戏页拿。**

## 协议速查

帧格式：`[2 字节 msgid 大端][protobuf body]`

| msgid | 名称 | 方向 | 结构 | 作用 |
|---|---|---|---|---|
| 10000 | wc1 | C→S | e8e,cv,w69,xol,kv | 登录 |
| 10001 | ubg | S→C | code | 登录回包，code=1 成功 |
| 22001/03/05/07 | dvx/rb1/gd7/e5x | C→S | — | 拉配装/枪/角色/道具 |
| **22064** | **nbe** | **C→S** | **type,id** | **刷枪（type=1 永久）** |
| **22066** | **ifm** | **C→S** | **type,id** | **刷角色** |
| 22015 | h3f | C→S | id,type | 解锁栏位 |
| 22020 | mev | C→S | id,type | 强化（扣合金） |
| 22052/22054 | n4o/nlf | C→S | id | 广告店买+领 |
| 22058 | i6d | C→S | id | 钻石店购买 |
| 22024/25/26 | x0h/p92/kto | S→C | 列表 | **增量下发** |

**拉包必须 22001+22003+22005+22007 四条一起发**，单独发 `22003` 只回角色。

## 关键参数

| 项 | 值 | 原因 |
|---|---|---|
| 发包间隔 | **≥500ms** | 低于 200ms 服务端静默丢包，无任何报错 |
| 每 40 条 | 歇 1.5 秒 | 防风控 |
| 拉包间隔 | 700ms | 四条错开 |

风控表现：`10001 {code:1013}` → 频率超了，停 30 分钟。`1014` 才是真封禁。

---

## 边界

- **服务端存不了 `ztv=-1`**。协议里没有「设置 ztv」的入口，只能客户端改写显示。
- **资源数量改不了**。所有发放接口都只传商品 id，数量由服务端查配置表，且有 limit。
- 广告商店刷完不会再生（`limit`）。

详见 `docs/protocol.md`。
