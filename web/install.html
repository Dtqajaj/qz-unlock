安装油猴脚本

装一次，之后进游戏自动刷，不用管地址栏

1装 Tampermonkey

打开 Tampermonkey 官网
安卓：装 Kiwi Browser，在里面装 Tampermonkey 扩展
iPhone：App Store 下 Userscripts（Safari 扩展）
电脑：Chrome / Edge 应用商店直接装

2装脚本

★ 点这里安装（推荐） 备用方式（GitHub 原始地址）

3上面都不行就用这个

复制脚本全文 → 在油猴里点「+」新建脚本 → 全选删掉 → 粘贴 → 保存（Ctrl+S）。

4装好之后

打开游戏登录，脚本自动开始刷，约 1 分钟。
刷完重进游戏，89 把枪都在。
打开游戏
